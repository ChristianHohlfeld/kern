Speicherung im Browser (Kern Studio, Kern Lehrer)

Die Anwendungen dieser Website speichern Daten ausschließlich lokal in Ihrem Browser, damit die von Ihnen genutzten Funktionen arbeiten können. Diese Daten verlassen Ihr Gerät nicht und werden nicht an mich übermittelt:

  • Local Storage (Kern Studio): die automatische Sicherung des geöffneten Levels, das zuletzt gespeicherte Level, Ihre Einstellungen und die Anordnung der Fenster (Schlüssel kern-studio.*).
  • Session Storage (Kern Studio): ein Zähler für Aktualisierungsversuche, der beim Schließen des Tabs gelöscht wird.
  • IndexedDB (Kern Lehrer und Kern Studio): im Lehrer trainierte Netze, damit Kern Studio sie auf demselben Gerät verwenden kann (Datenbank kern-lehrer).
  • Service Worker und Cache Storage (Kern Studio): eine Kopie der Editor-Seite, der Symbole und des Manifests, damit der Editor als App installiert und offline genutzt werden kann.

Der Editor fragt beim Start und, solange er geöffnet ist, etwa einmal pro Minute die Datei build.json vom Server ab, um eine neuere Version zu erkennen. Dieser Abruf geht wie jeder Seitenabruf an GitHub Pages (siehe oben) und enthält keine Daten aus Ihren Projekten. Dateien, die Sie im Editor öffnen (Levels, Texturen, Klänge), werden nur in Ihrem Browser verarbeitet; Speichern und „Package Game“ legen Dateien auf Ihrem Gerät ab. Die Zwischenablage wird nur genutzt, wenn Sie selbst kopieren oder einfügen.

Die Speicherung ist unbedingt erforderlich, damit ich die von Ihnen ausdrücklich gewünschte Funktion (Bearbeiten, Speichern und Offline-Nutzung des Editors) bereitstellen kann; eine Einwilligung ist dafür nach § 25 Abs. 2 Nr. 2 TDDDG nicht erforderlich. Soweit dabei personenbezogene Daten betroffen sein sollten, ist Rechtsgrundlage Art. 6 Abs. 1 lit. b und f DSGVO. Sie können diese Daten jederzeit löschen, indem Sie in Ihrem Browser die Websitedaten für diese Website löschen; dabei gehen nicht exportierte Projekte verloren.

Mehrspieler

Mehrere Spieler im selben Browser (verschiedene Tabs) werden lokal über den Browser verbunden; dabei werden keine Daten über das Netz übertragen. Eine Verbindung zu einem Mehrspieler-Server (Relay) wird nur aufgebaut, wenn Sie selbst die Adresse eines solchen Servers angeben (Parameter relay= in der Adresse des Spiels).
