Working with a 3D scene

The Editor3D R.U.B.E-style workflow, running on the Kern engine. Use Space → Add for bodies, fixtures, joints, image planes and sampler volumes.

Switch with B / F / V / J / I / M / W. Transform with T/G, R, S, constrain with X/Y/Z, type exact numbers, and use C for the 3D cursor.

Run opens an independent Box3D player. Left-drag dynamic bodies with a real Box3D MotorJoint. On touch devices switch Orbit to Grab to pull bodies.

Games: give a body the Player role and a control (roll, drive, fly, walk) in its Properties → Game group, add pickups, hazards and a goal, then Run. File → Export game writes a standalone HTML game. Try File → Examples → Game: Roll & Collect.
