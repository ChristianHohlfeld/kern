How it works

Every worker runs its own ducks in Kern's engine (the same servos, sensors and 50 Hz controller as in Kern Studio) and acts with the current policy. The learner gathers their steps and improves the policy with PPO, the recipe Pollen Robotics trains the robot's networks with. The result is an ONNX file in the shape of Pollen's networks, so Kern Studio and the robot itself can load it.

Keep this tab open while it trains; on a phone, plug it in. More workers use more cores.

Every 25 iterations the network is saved on this device for Kern Studio: the Micro Duck's "jump" move (Logic node Robot Move, move "jump") runs the latest jump network, in open Studio tabs at once.
